Introduccion al desarrollo web.

En desarrollo web se aprenden los fundamentos para construir sitios y aplicaciones: la estructura de las páginas con HTML, su diseño visual y adaptabilidad con CSS, y la interactividad con JavaScript. También se abordan los conceptos básicos del modelo cliente-servidor, el funcionamiento del protocolo HTTP y las bases del desarrollo back-end y de bases de datos, para comprender cómo se conectan todas las partes de una aplicación web.

Desarrollo Web

- ¿Que es una pagina web?

Una página web es un documento digital, escrito principalmente en HTML y estilizado con CSS, que se almacena en un servidor y se visualiza mediante un navegador. Puede contener texto, imágenes, videos y enlaces a otras páginas.

- ¿Cómo funcionan?

Funcionan bajo el modelo cliente-servidor:

  • El usuario escribe una dirección (URL) en el navegador (cliente)
  • El navegador envía una solicitud HTTP/HTTPS al servidor que aloja la página.
  • El servidor procesa la solicitud y devuelve una respuesta con los archivos necesarios (HTML, CSS, JavaScript, imágenes).
  • El navegador interpreta esos archivos y muestra la página al usuario.

- Tipos de paginas web

Tipos de páginas web Descripción Ejemplos
Estáticas Su contenido es fijo y se muestra igual a todos los usuarios, tal como fue escrito en los archivos HTML. Son rápidas y sencillas, pero para modificarlas hay que editar el código. Una página de presentación o un portafolio básico.
Dinámicas Generan su contenido en el servidor o en el navegador según la interacción del usuario, una base de datos o datos en tiempo real. Permiten inicio de sesión, formularios, carritos de compra y contenido personalizado. Una tienda en línea o una red social.

- Diferencias entre un sitio web y una aplicación web

Aspecto Sitio web Aplicación web
Objetivo Informar o presentar contenido Realizar tareas y procesos
Interacción Baja (navegar, leer) Alta (el usuario ingresa y procesa datos)
Autenticación Generalmente no requerida Normalmente requerida
Ejemplos Blog, página institucional Gmail, sistema de conciliación bancaria, Google Docs
